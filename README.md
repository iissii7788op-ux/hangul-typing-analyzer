# 한글 타자 오류 패턴 분석 및 맞춤 연습 문장 생성 서비스

정보과학 프로젝트 · 2510 이정현

## 무엇을 만드나

기존 타자 연습 사이트는 **분당 타수와 정확도 퍼센트만** 알려 준다.
내가 *어떤 글자에서 왜* 틀리는지는 알려 주지 않아서, 틀리는 부분만 골라 연습할 방법이 없다.

이 서비스는 제시 문장을 따라 타이핑하면 **자모 단위로** 어떤 글자를 어떤 글자로 잘못 쳤는지
분석해서, 자판 히트맵 · 취약 자모 순위표를 보여 주고, 그 자모가 집중된 **맞춤 연습 문장**을
자동으로 만들어 준다.

## 기능 범위 (1차시 확정)

### 1단계 — 프론트엔드만으로 동작 (2~5차시)
- [ ] 제시 문장 / 타이핑 입력창 / 시작·다시하기 버튼 화면
- [ ] 입력 중 실시간 오답 색 표시, 글자별 키 입력 시각 기록
- [ ] 자모 단위 편집 거리(DP) + 역추적 → **오류 쌍** 추출 (예: ㅕ → ㅛ)
- [ ] 오타 유형 분류: 교체 / 삽입 / 삭제 / 자리바꿈
- [ ] 교체일 때 두벌식 자판 좌표로 키 사이 거리 계산 → 옆 키 오타 vs 먼 키 오타
- [ ] 자모별 평균 입력 시간 → 틀리진 않지만 느린 자모 찾기
- [ ] 배낭 알고리즘으로 취약 자모가 집중된 맞춤 연습 문장 생성
- [ ] Vercel 배포

### 2단계 — Supabase 연결 (6~8차시)
- [ ] 연습 기록 저장 (제시 문장, 입력 문장, 시간, 정확도, 날짜)
- [ ] 사용자별 자모 오류 쌍 / 평균 입력 시간 **누적** 집계
- [ ] 회차별 정확도 추이 그래프, 누적 취약 자모 기록 화면

### 이번 프로젝트에서 하지 않는 것
- 맞춤법 검사 (오타 원인 분석이 목적이지 교정이 목적이 아님)
- 세벌식 등 두벌식 외 자판
- 실시간 멀티플레이 대결

## 자모 분해 원리 메모

한글 완성자(가~힣)는 유니코드에 규칙적으로 배열되어 있다.

```
코드 = 0xAC00 + (초성번호 × 21 + 중성번호) × 28 + 종성번호
```

초성 19개 · 중성 21개 · 종성 28개(받침 없음 = 0번)이므로,
한 초성이 차지하는 칸은 21 × 28 = 588칸.

이 식을 거꾸로 풀면 사전 없이 나눗셈만으로 분해된다.

```
offset  = 코드 - 0xAC00
종성번호 = offset % 28
중성번호 = (offset / 28) % 21
초성번호 = (offset / 28) / 21
```

검산 — `안`(0xC548) → offset 6472
→ `6472 % 28 = 4`(ㄴ), `6472/28 = 231`, `231 % 21 = 0`(ㅏ), `231/21 = 11`(ㅇ) → ㅇ,ㅏ,ㄴ ✅

### 다음 차시로 넘길 과제
`값` → `ㄱㅏㅄ`으로 나온다. `ㅄ`은 **한 글자로** 나오지만 두벌식 자판에서는 ㅂ, ㅅ **두 키**를
눌러야 한다. 자판 좌표로 오타 거리를 계산하는 4~5차시에는 겹받침(ㅄ, ㄺ…)과
복합 모음(ㅘ, ㅢ…)을 실제 키 단위까지 한 번 더 쪼개야 한다.
